## What Was Done

1. **The refusal names its cause.** `graphs/sdd.toml` poured `contract`'s `fail` and `unrunnable` ports
   into one `refuse` node reading "the agent failed or the criteria could not run". Five wrong
   diagnoses in one night came from that sentence. Split, with `graphs/spec.toml` routing both arms and
   the pin chain (`spec` → `queue` → `self-improve`/`night`) re-fixed to a fixed point.
2. **`refuse` reports the arriving arm** (`crates/pii-graph/src/nodes/refuse.rs`, 8 tests with contrast
   against the old code): a reason that exists always wins; a payload with no reason names its arm.
3. **Tests own their HEAD.** Spec 441 (`scripts/autonomy/tests/lane-graph-select.test.sh` builds its own
   `git init` scratch repo) and spec 442 (the same for `crates/*/tests`, plus
   `lane-pin-head`'s clean case). `scripts/checks/graph-edits-are-testable.sh` fails and names any test
   that starts the lane without a repo, and fails when it inspects nothing: 60 shell + 340 Rust tests,
   9 lane starters own their HEAD.
4. **Criteria that name future files must fail, not vanish.** Nine criteria across 431/435/436 invoked
   files their own row creates, so the contract judge returned `unrunnable` and the queue could never
   authorise them. Rewritten as `test -f X && <command>`: exit 1 today, 0 when done.
5. **The item gate is cheap again.** `scripts/gate-touched-crates.sh` demanded `--lib` of every touched
   crate; `pii-cli` is a binary. Flags removed, and the wrapper now runs `GATE_STEPS=gate-steps-quick.txt`
   `QG_SKIP_COVERAGE=1` — what `scripts/autonomy/env.sh` has said since October.
6. **One worker ran end to end.** Row 431 was dispatched, ran 431's implementation (a new judge graph, a
   check script, 7 tests) and returned `rc=1` only because the criteria ran a stale binary.
