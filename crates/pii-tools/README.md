# pii-tools

`pii-tools`: the built-in tool set.

Public modules: `bash`, `fs`, `memory`, `mqtt`, `run`, `sandbox`, `search`, `worktree`.

Depends on: `pii-abi`, `pii-channels`, `pii-core`, `pii-model`, `pii-observe`, `pii-proto`, `pii-uds`.
Used by: `pii-cli`, `pii-mcp`, `pii-server`.

11 source files; 3 integration test files under `tests/`. Test with `cargo test -p pii-tools`.
